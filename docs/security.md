# Security design and assurance

The browser is untrusted. SvelteKit owns the HttpOnly host-only session cookie and forwards only explicitly allowed methods/routes to loopback Rust. Rust owns authorization, prices and state transitions. PostgreSQL enforces relationships, leases, transactional financial transitions and immutable evidence. Production rejects fixture users and incomplete provider/storage/policy configuration.

The selected cloud architecture uses one region with availability-zone redundancy. It provides no claim of cross-region or cross-account disaster recovery. Decoders are a deliberately narrow process boundary; ClamAV shares its ECS worker task role and is isolated from mounted application secret files, not assigned a separate IAM identity.

Provider credentials, incoming private payloads, session cookies and query strings must not enter logs. SQL statement logging is disabled for credential administration. Administrative actions store constrained evidence/reasons; operators must avoid personal documents, bank details or secrets in free-text fields.

Authenticated profile, content, checkout, payout, moderation and privacy changes revalidate account status, session validity and any required recent MFA after locking the account row. The session query runs after the lock is acquired so a concurrent recovery cannot leave a request authorized by an earlier database snapshot. Multiple account locks use stable UUID order before creator or domain rows. External provider success records remain durable for reconciliation even when the initiating session loses eligibility; hosted capabilities require a renewed eligibility check before being returned. Legacy upload ownership is recorded before storage access, and its bounded PUT serializes with account freeze. Historical object versions and uncertain external outcomes still require the existing privacy and provider reconciliation procedures.

Moderator post inspection is an explicit recent-MFA endpoint with an immutable access event. It does not alter entitlements or make public feed links privileged. Private media endpoints independently validate authorization when the evidence bytes are requested; an expired inspection session cannot keep fetching restricted media.

Automated tests and advisory scans are bounded observations, not a security certification, legal conclusion, production SLO or substitute for independent assessment of the deployed service.
