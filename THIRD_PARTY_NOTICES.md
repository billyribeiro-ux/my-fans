# Third-party components

The original application code is private (`UNLICENSED`); this repository grants no public redistribution license for it. Dependency licenses remain with their respective owners. Lockfiles identify the exact dependency graph, and the private release workflow collects notices, corresponding sources, patches and build instructions alongside the images.

The packaged media tools use FFmpeg 9.0.2 built with `--enable-gpl --enable-libx264`. The GPL-enabled FFmpeg build is governed by GPL terms, rather than the default LGPL-only configuration. The Rust application launches FFmpeg as a separate process. See [FFmpeg's licensing documentation](https://ffmpeg.org/legal.html), [corresponding release source](https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz), and `scripts/install-ffmpeg.sh` for the source checksum and build configuration. libx264 is supplied by Alpine 3.24's `x264-libs` package. The corresponding-source release bundle includes its exact installed package version, matching Alpine APKBUILD, upstream sources, patches and license declarations. The container's `/lib/apk/db/installed` metadata and runtime SPDX inventory record the packaged version.

The [release workflow](docs/release.md) inventories both application and scanner images and retains FFmpeg/Node/ClamAV sources, the patched scanner Cargo lock, Cargo/npm dependency sources, and matching Alpine source recipes/patches. Download and retain the verified bundle before GitHub artifact retention expires. License obligations attach to the actual distribution; codec patent and commercial terms depend on the product and launch markets.

Lucide supplies the SVG icon library; see [Lucide license](https://lucide.dev/license). Seed photographs load from public Unsplash image URLs and are sandbox fixtures. Replace or approve production imagery and document its usage rights. DM Sans and Manrope are served locally with their upstream SIL Open Font License notices in `apps/web/static/fonts`; the application does not need a Google Fonts connection.
